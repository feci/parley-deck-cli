## Findings

### [MAJOR] Missing runstate.Attention badge on Home tab (D14)
- **File:** [internal/tui/live.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/live.go#L1057-L1078), [internal/tui/layout.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/layout.go#L65)
- **Why:** Consensus D14 explicitly calls for rendering the `runstate.Attention` badge on the Home tab phase column. While a helper function `attentionBadge(value)` is defined in `layout.go`, it is never invoked anywhere in the codebase. As a result, the Home tab lists ideas and recent runs without any attention highlighting.
- **Suggested Fix:** In `refreshHomeRuns`, resolve and store the attention state for each idea (e.g., by matching it against its latest run's attention state). In `renderHome` (both for Ideas and Recent Runs), render this status badge by passing it to `attentionBadge(...)` next to the phase chip.

### [MAJOR] Missing 2-space indentation on silent-agent placeholder (D12)
- **File:** [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L613-L651) (`renderSilentPlaceholder`)
- **Why:** Consensus D12 specifies that the buffered-agent placeholder content must be indented. Currently, all lines generated by `renderSilentPlaceholder` are printed flush against the left margin. This breaks visual alignment with the rest of the TUI transcripts and fallback placeholders, which consistently use a 2-space indentation prefix.
- **Suggested Fix:** Prepend `"  "` (two spaces) to every line printed in `renderSilentPlaceholder`.

### [MINOR] Inconsistent title for step 8 in Protocol tab pipeline (D11)
- **File:** [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L551) (`renderProtocolPanes`)
- **Why:** In `renderProtocolPanes`, the pipeline step name is retrieved strictly via `stepTitles[stepNames[i]]`. Since `stepNames[8]` is `"complete"`, it always renders as `"Complete"`. However, if the current state is actually a fix-up cycle, `displayStep` returns step name `"fix-up"`. In this state, the collapsed ribbon correctly renders `Ph 8: Fix-Up` (via `p.StepName`), but the Status/Protocol tab incorrectly displays `[▶] 8 Complete`.
- **Suggested Fix:** If `i == p.Step`, use the actual snapshot step name `p.StepName` to look up the title (i.e., `title := stepTitles[p.StepName]`) to ensure the correct label (`"Fix-Up"` or `"Complete"`) is displayed.

### [MINOR] Redundant round denominator in collapsed ribbon format (D9)
- **File:** [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L374) (`renderRibbon`)
- **Why:** In `renderRibbon`, steps 1 and 2 format the round status as `(R%02d/%d)`. This outputs strings like `(R01/4)` or `(R02/4)`. However, consensus D9 explicitly requires the collapsed layout to display `(R01)` or `(R02)` without the total rounds denominator.
- **Suggested Fix:** Modify the format string to `(R%02d)` and omit the total rounds argument, yielding `fmt.Fprintf(&b, " (R%02d)", p.CurrentRound)`.

### [MINOR] Noisy narrator and placeholder activity lines (D7)
- **File:** [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L205) (`narratorLine`), [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L668) (`recentAgentActivity`)
- **Why:** The narrator lines and recent activity blocks prepend the raw event type (e.g., `run.phase`, `agent.finished`, `agent.started`) to the human-readable text. This results in verbose and repetitive lines such as `── 15:04:05 agent.finished hermes wrote artifact ──` or `· 15:04:05 agent.started hermes`.
- **Suggested Fix:** In `narratorLine`, use only `s.Text` when it is already descriptive, or map the raw `e.Type` to a concise action word (e.g., if `e.Type == "agent.started"`, format as `hermes started`).

### [NIT] Redundant status rendering in Home ideas list
- **File:** [internal/tui/live.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/live.go#L1062) (`renderHome`)
- **Why:** When an idea has no active run or phase chip, `chip` defaults to `idea.Status`. The formatting string `%-34s %-22s %s` then prints the status string twice side-by-side (e.g., `kickoff                kickoff`), which is redundant.
- **Suggested Fix:** If `chip == idea.Status`, print a neutral placeholder like `—` for the phase column.

### [NIT] Missing ASCII fallback for braille spinner (D8)
- **File:** [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L275-L302) (`agentGlyph`)
- **Why:** Consensus D8 specifies that the running-active braille spinner should fall back to an ASCII `*` in non-UTF-8 terminals. There is currently no check or fallback mechanism in `agentGlyph`.
- **Suggested Fix:** Implement a check for ASCII mode (if available on the model or options) and return `*` instead of the braille frames when active.

### [NIT] Slow spinner animation speed
- **File:** [internal/tui/protocolui.go](file:///Volumes/My%20Shared%20Files/AI_WORKSPACE/parley-deck/parley-deck-cli/internal/tui/protocolui.go#L286) (`agentGlyph`)
- **Why:** The spinner index is calculated via `m.now.Unix() % 10`. Since `m.now` only updates once per second on the `elapsedTickMsg`, the spinner rotates at an extremely slow speed of 1 frame per second, making it look laggy or frozen.
- **Suggested Fix:** Consider basing the frame rotation index on a higher-frequency clock or sub-second interval if available, or document this as a minor visual limitation of the 1s tick.

The async snapshot architecture and driver integration are solid and fully tested, but the TUI requires visual alignment fixes, removal of log noise in the narrator stream, and the implementation of the missing Home tab attention badges.
