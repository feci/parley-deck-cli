# ASD source notes

Consulted with ego-browser on 2026-10-13. These notes summarize public sources.
They do not reproduce the dictionary or the full standard.

- Official download page: https://www.asd-ste100.org/STE_downloads.html#article02-2l
  The heading says: "ASD-STE100 (Issue 9, January 2025)".
  The page identifies this as the current issue and provides a free-copy request form.
- Official FAQ: https://www.asd-ste100.org/STE_faq.html
  Under "When will the next issue of ASD-STE100 be published?":
  "The current issue is 9, released in January 2025. The next issue 10 is scheduled for January 2028."
- The FAQ describes separate writing rules and an approved dictionary.
  Technical nouns and verbs can use documented subject terminology under the standard's rules.
  An `-ing` form can be a permitted technical noun. A suffix ban would be inaccurate.
  Procedures use direct commands and active voice. Description can use passive voice when the actor is unknown.
  Tools are optional. A tool does not replace the standard.

The exact rule numbers and full dictionary have not been inspected.
