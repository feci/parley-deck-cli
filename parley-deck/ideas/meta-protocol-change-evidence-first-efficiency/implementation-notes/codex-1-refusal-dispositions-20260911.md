## Implemented behavior

Driver and helper failures retain separate immutable observations before
canonical publication. A unique attempt directory identity enters each frozen
request; its digest correlates the two observers without inventing two model
invocations. A helper retains its own failure even if its parent stops. Missing
results do not establish process termination. Failures before a safe canonical
idea scope is established cannot write to arbitrary locations and stay explicit.

The schema accepts bounded typed stages, safe optional labels, available request,
report and receipt hashes, and actual helper criterion statuses/command hashes.
Unsafe labels are null. No raw command, prompt, provider output, environment or
error prose enters canonical records; the failure stage identifies the boundary,
while detailed diagnostics remain private. Strict canonical JSON rejects aliases,
duplicate/unknown/missing fields, unsafe labels and inconsistent identities.

Pending observations live in worktree-specific Git administration, independently
of root runtime ignore rules and the publication lock. The parent commits this
attempt's observations; `evidence refusals inspect` is read-only, and `recover`
requires an exact inspected SHA256. Shared-guard publication never overwrites a
conflicting record or recreates a lost lock. It commits only the selected path,
checks committed bytes and preserves unrelated staged/working changes. Exact
replay verifies the existing commit; later and duplicate exact observations stay
retained. Different content under one observation identity blocks recovery.

After a crash before rename, recovery can remove matching partial canonical
staging files only under the original shared guard, with the selected digest in
their names and bytes that are a prefix of the exact retained record. Divergent
or unrelated staging remains unresolved. Incomplete pending observations remain
visible; the command cannot reconstruct unknown lost content. Git/commit failure
never becomes acceptance. Non-Git observations claim local persistence only.

Canonical refusal files stay in the tested-tree digest. Publication invalidates
old tree evidence and requires fresh checks. Pending/uncommitted/incomplete
observations block verification and final independent acceptance. Recovery never
executes tests, calls a model, grants budget, supplies a signature or creates a
successful receipt. Report and receipt write failures recover with preserved
observations, exact publication where needed, and fresh real checks/helper calls.
