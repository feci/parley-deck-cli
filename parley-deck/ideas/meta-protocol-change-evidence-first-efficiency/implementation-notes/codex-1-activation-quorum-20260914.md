## Implemented boundary

Original members are derived from the complete hash-verified baseline archive
and Policy.Baseline. They must be unique safe identities with the original
implementer and at least one independent participant. Captured request freezing,
ticket preparation, permission to reuse/execute and captured source authority
require the selected verifier in that quorum and exact ordered membership in
both before/after archives. Reconciliation independently checks the parent
request's members; matching a later changed live prompt is insufficient.
Unchanged observations compare their before archive with activation membership
before the existing current-scope/criterion checks.

No policy or archive wire format changes. Explicit original criteria remain
Policy.Criteria's contract. Membership decoding shares the existing frontmatter
boundary but does not impose named-check syntax on lower-level activation callers
that previously supplied criteria directly. Missing/malformed legacy membership
or historical contradictory resolutions refuse, without inventing old members or
rewriting participant artifacts. This pins activation-time evidence, not absent
earlier Phase-0 history, and does not authorize an amendment of the idea quorum.

A bad first patch still records its real terminal, after-source and original
spend. The new permission predicate is not attached to generic state/terminal
capture. StopCapturedVerification retains pre-existing structural ticket, launch,
invocation, state/history and process attribution checks while omitting only the
new execution permission. A synthetic old ticket with a now-invalid verifier
can retain an exact stop; it cannot release a new execution callback or launch.
No helper/process was claimed in that test, so it does not establish historical
descendant inactivity. Full real process-stop coverage remains separate.

Cleanup's existing dependency on all historical resolved state/evidence is not
removed. An inconsistent older resolution can still block stop. Fixing that
requires the separately owned helper/workflow recovery boundary, not bypassing
all old evidence merely because membership was invalid.
